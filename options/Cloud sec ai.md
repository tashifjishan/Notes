# Phase 1: Programming Foundation

## Month 1–3

### Goal

Become comfortable with Python, Git, Linux basics, SQL, and problem solving.

## Books

### 1. **Python Crash Course, 3rd Edition — Eric Matthes**

Use this as your main beginner Python book. It is project-based and teaches Python by building real applications. ([No Starch Press][2])

Read:

Chapters 1–11 for Python basics
Chapters 15–17 for data handling
Chapters 18–20 for web app basics

### 2. **Automate the Boring Stuff with Python — Al Sweigart**

Use this for practical automation thinking: files, Excel, web scraping, email, PDFs, and daily task automation.

### 3. **Pro Git**

Use this for Git and GitHub fundamentals. The official Pro Git book covers Git basics, branching, GitHub, distributed Git, and Git tools. ([Git][3])

## Udemy Courses

### 1. **The Complete Python Bootcamp From Zero to Hero in Python — Jose Portilla**

Good for Python fundamentals, quizzes, coding exercises, homework assignments, and portfolio projects. ([Udemy][4])

### 2. **The Complete SQL Bootcamp: Go from Zero to Hero — Jose Portilla**

Use this for PostgreSQL and database querying. The course focuses on reading and writing SQL queries and says the skills apply to PostgreSQL, MySQL, SQL Server, Redshift, Oracle, and more. ([Udemy][5])

### 3. **Git & GitHub Bootcamp / Git Complete**

Take one beginner-friendly Git course only. Do not waste too much time here.

## Weekly plan

**Week 1–4:** Python basics
Variables, loops, functions, lists, dictionaries, files.

**Week 5–8:** Python projects
Build small automation scripts.

**Week 9–10:** SQL
SELECT, JOIN, GROUP BY, subqueries, indexes.

**Week 11–12:** Git + GitHub
Commits, branches, pull requests, README files.

## Projects to complete

1. File organizer script
2. CSV cleaner script
3. Simple expense tracker using Python + SQLite/PostgreSQL
4. GitHub portfolio with clean README files

## Completion standard

You should be able to:

Write Python scripts without copying every line
Use GitHub properly
Write SQL joins and aggregations
Explain your code clearly

# Phase 2: Linux + Networking + Backend APIs

## Month 4–6

### Goal

Understand how servers work, how networks communicate, and how backend APIs are built.

## Books

### 1. **How Linux Works, 3rd Edition — Brian Ward**

This is one of the best Linux foundation books. It covers Linux internals, networking, virtualization, containers, shell scripting, devices, and processes. ([No Starch Press][6])

### 2. **Computer Networking: A Top-Down Approach**

Use this to understand TCP/IP, DNS, HTTP, routing, TLS, and how real internet communication works.

## Udemy Courses

### 1. **Linux Mastery / Linux Command Line course**

Pick one course focused on commands, permissions, processes, services, logs, SSH, shell scripting, and package management.

### 2. **The Complete Networking Fundamentals Course**

This course covers network fundamentals, LANs, IP addressing, subnetting, switches, routers, OSI, TCP/IP, DHCP, DNS, and ACLs. ([Udemy][7])

### 3. **FastAPI / Python API course**

FastAPI is a modern Python framework for building APIs using type hints. ([FastAPI][8])

## Weekly plan

**Week 13–16:** Linux
Filesystem, users, permissions, processes, systemd, logs, SSH.

**Week 17–20:** Networking
IP, subnetting, DNS, HTTP, HTTPS, TLS, ports, firewalls.

**Week 21–24:** Backend APIs
Build APIs with Python, FastAPI, PostgreSQL, authentication, logging.

## Projects to complete

1. Linux server setup on a virtual machine
2. FastAPI CRUD API with PostgreSQL
3. API with login/authentication
4. API logs + error handling
5. Deploy locally using Linux commands

## Completion standard

You should be able to:

SSH into a server
Read logs
Understand ports and DNS
Build a working API
Connect API to a database
